# TAGO 버스정류소정보 API 명세 및 완결성 검증 리포트

## 1. 개요
- **서비스명**: 국토교통부 (TAGO) 버스정류소정보조회 서비스 (`BusSttnInfoInqireService`)
- **데이터셋 ID**: `15098534`
- **기본 Endpoint**: `https://apis.data.go.kr/1613000/BusSttnInfoInqireService`

---

## 2. 정류소번호 목록조회 (`getSttnNoList`) 명세

### 1) 요청 파라미터 (Request Parameters)
| 파라미터명 | 구분 | 타입 | 설명 | 비고 |
| :--- | :--- | :--- | :--- | :--- |
| `serviceKey` | **필수** | String | 공공데이터포털 발급 인증키 | 환경변수 `TAGO_SERVICE_KEY` 사용 |
| `cityCode` | **필수** | Number | 행정구역 5자리 도시코드 | 예: 화성시(`31240`), 남양주시(`31130`) |
| `nodeNm` | 선택 | String | 검색할 정류소 명칭 | 생략 시 해당 도시 전체 정류소 대상 |
| `nodeNo` | 선택 | Number | 검색할 정류소 번호(5자리 단축번호) | 생략 시 전체 정류소 대상 |
| `numOfRows` | 선택 | Number | 한 페이지 결과 수 | 기본값 10, 최대 1000 |
| `pageNo` | 선택 | Number | 페이지 번호 | 기본값 1 |
| `_type` | 선택 | String | 데이터 형식 (`json` 또는 `xml`) | 기본값 xml |

> **검색어 생략 시 동작 확인**:
> `nodeNm`과 `nodeNo`를 전달하지 않고 `cityCode`만 전달하면, 해당 지자체 BIS에 등록된 **도시 전체 정류소가 `totalCount` 기준으로 전량 페이지네이션 조회**됩니다.

### 2) 응답 필드 (Response Fields)
| 필드명 (XML/JSON 태그) | 대소문자 표기 | 국문 설명 | 데이터 타입 | 샘플 값 |
| :--- | :--- | :--- | :--- | :--- |
| `nodeid` | 소문자 | 정류소 고유 ID | String | `GGB222001318` |
| `nodenm` | 소문자 | 정류소 명칭 | String | `도농역.동화중고교.다산자이` |
| `nodeno` | 소문자 | 정류소 5자리 단축번호 | Number/String | `23927` |
| `gpslati` | **소문자** | 정류소 Y좌표 (WGS84 위도) | Float | `37.6051167` |
| `gpslong` | **소문자** | 정류소 X좌표 (WGS84 경도) | Float | `127.1557500` |

## 3. `tago_stops_full.parquet` 수집 완결성 검증

`src/collectors/tago_stops_full.py`는 각 대상 지자체별로 `nodeNm`/`nodeNo` 검색어 없이 `cityCode`로 단독 호출하여 전체 `totalCount`를 취득한 뒤, 1,000건 단위로 전체 페이지를 순회 수집하였습니다.

### 지자체별 정류소 총계 및 파케이 수집 결과
| 지자체명 | 도시코드 (`cityCode`) | API 응답 `totalCount` | 파케이 저장 건수 (`tago_stops_full.parquet`) | 수집 완결성 |
| :--- | :--- | :--- | :--- | :--- |
| 화성시 | `31240` | 3,376 | 3,376 | 전수 수집 완료 (100%) |
| 김포시 | `31230` | 928 | 928 | 전수 수집 완료 (100%) |
| 성남시 | `31020` | 1,502 | 1,502 | 전수 수집 완료 (100%) |
| 하남시 | `31180` | 437 | 437 | 전수 수집 완료 (100%) |
| 남양주시 | `31130` | 2,177 | 2,177 | 전수 수집 완료 (100%) |
| **합계** | **5개 지자체** | **8,420** | **8,420** | **전수 일치** |

> **1,644건과의 관계 규명**:
> * `1,644건`은 정류소 전체 수가 아니라, 6D 단계에서 274개 주거 클러스터 각각에 대해 최단거리 상위 6개 후보를 선별한 `exports/stop_candidates.csv` ($274 \times 6 = 1,644$)의 레코드 수입니다.
> * 모수가 되는 `tago_stops_full.parquet`는 위 5개 지자체의 정류소 전수(8,420건)를 누락 없이 온전히 보관하고 있으므로, G2의 "정류소 부재(`Reason.G2_STOP_NOT_FOUND`)" 판정은 수집 누락에 의한 오탐이 아님이 확인되었습니다.
