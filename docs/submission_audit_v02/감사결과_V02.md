# V02 감사 결과와 V01 정정

## 결론과 정정 사유

V01은 `data/curated/source_registry.csv`만 분석 입력으로 사용하여 사용자의 사람 검수 이력을 놓쳤다. `evidence/candidate_registry.csv`뿐 아니라 `data/source_registry_verified_final_resolution.csv`에 상세 검수 이력이 있었다. 또한 기존 배차 추정표의 생성 코드가 `scratch/`에 있었으나 배포와 계보 확인에서 누락했다. V02는 이 두 누락을 정정한다. V01은 비교용 보관본이며 최신 사실로 사용하지 않는다.

## 사람 검수의 반영

- 축약 대장과 최종 보완대장 각각 197행을 결합했다. 상태는 사람 검수 131, 미검수 15, 제외 37, 중복 14행이다.
- 축약 대장의 후보 ID는 재사용되므로 후보 ID·원문 경로·원문 SHA-256과 지구명을 함께 사용했다. 이후 상세 대장은 source_id·원문 해시·상태 일치를 확인했다.
- 사람 검수 131행의 검수자 `parkd`와 2026-09-02의 세 검수 시각(19:38, 20:11, 20:22, +09:00)을 원문 기재대로 보존했다. V02가 새로 사람 검수를 수행했다고 기록하지 않는다.
- 사람 검수 131행은 고유 문서 해시 110개에 연결된다. 사건 수와 문서 수는 다르다.
- 최종 보완대장에는 수정 인용문 79행, 페이지·섹션 변경 83행 등 축약 대장에 없는 내용이 있었다. 필드별 전후 값은 `review_changes_v02.csv`에 있다.
- `exact_excerpt`라는 열 이름과 달리 요약·재서술이 들어간 행이 있다. 현재 자동 문자열·필드 검사에서 검수 완료 중 35행 통과, 96행 보완 표시가 나온다. 이는 사람 검수 기록의 취소도, 96행이 허위라는 판단도 아니다. `review_queue_v02.csv`의 보완과 미검수 15행을 구분한다.
- 정류소 검수 1행은 검수자 박도현·검수 시각·승격 로그·지도 이미지 4개에 연결된다. 문서 사건 131행과 합산하지 않는다. 루트 `manual_overrides.csv`의 좌표 보정 6행은 작성자가 AI이며 사람 검수로 승격하지 않는다.

## 코드와 재현성

- `scratch/calc_headway_v7.py`의 계산 함수를 읽기 전용으로 재실행했다. 기존 `headway_observed.parquet` 72행·11열은 결측 표현을 정규화하면 모든 열이 일치한다. `headway_lineage_v02.json`에 코드 해시와 비교 결과를 기록했다.
- 기존의 3일 분석기간과 3개 노선 제외는 고정된 선택이다. 제외 노선은 실제로 공표정보 테이블에 없는 노선들과 일치했다. V02 재현에서는 이 목록을 데이터의 집합 차이로 도출한다.
- 전체 관측 6일·15노선의 예측 변화 추정치를 추가 산출했다. 결측 유지 시 이벤트 검출 그룹 170개 중 97개는 이벤트가 4개 미만이다. 전체 가능한 15×6×2=180개 그룹과 검출 그룹 수를 혼동하지 않는다.
- 풀링된 추정 간격 중앙값은 20분이다. 빈 응답을 0으로 처리하는 반사실 민감도에서는 하위사분위수가 15분에서 10분으로 이동한다. 원본을 0으로 채우지 않으며 실제 배차간격이나 준수율로 해석하지 않는다.
- `src/metrics/day123_full_refresh.py`의 고정 사람 검수 0·고정 FAIL 및 과거 보고서 숫자는 보관 코드의 문제로 명시하고 V02 입력에서 제외한다. V02 사람 검수 집계는 실제 결합 행에서 계산한다.
- 문서 연결 점검 버전은 `v3.1-resolution-import`다. 이 점검은 기존 문서 보고서의 종합 GO 판정이나 정류소 G1~G6와 동등하지 않다. 정류소 게이트 v2.3은 변경하지 않았다.
- 날짜·원문 문구를 CSV 주석으로 기록하는 것은 출처 있는 데이터 입력이다. 계산 결과를 미리 채우는 하드코딩과 구별한다. 논문 문장은 해당 분석 스냅샷의 편집 결과이므로 입력 변경 시 재편집과 검증이 필요하다.

## 수집 및 데이터 품질

사용자가 언급한 07~09시·17~19시의 간격 수집 원자료는 `evidence/arrival_raw`에 저장돼 있다. 오전 120개, 오후 139개 원파일의 항목 수를 원장과 대조했으며 불일치는 없었다. `scratch/_task_log.txt`의 일반 호출 259건과 SWEEP 재시도 3건은 원장 262행과 키·상태·항목 수가 일치했다. Windows의 TAGO_Arrival_AM/PM 예약 작업은 읽기 전용으로 존재를 확인했다.

추가 제공된 `C:/Users/parkd/tago`에는 `run_arrival_snapshot.bat` 한 파일이 있었다. 전체 내용을 확인했고, 현재 프로젝트로 이동하여 `python -m src.collectors.arrival_snapshot`을 실행하고 `scratch/_task_log.txt`로 출력을 저장하는 연결을 확인했다. 배치 원본 해시는 `cd6f7441969ee6ac8137dee26d06ba3a466f10c69f4d9213383e3dee453c3e3b`이며 참조 사본을 `batch_reference/`에 보관했다. 원본 폴더를 수정하거나 배치를 실행하거나 예약 작업을 등록·변경하지 않았다. 추가 폴더 목록은 `tago_folder_inventory_v02.csv`에 별도로 기록한다.

원자료의 6,354개 항목은 모두 `arrprevstationcnt, arrtime, nodeid, nodenm, routeid, routeno, routetp, vehicletp` 구조다. 이는 실제 호출 시각에 내려받은 도착예정정보이며 가상 데이터가 아니다. 다만 실제 차량 식별자나 실제 정류소 통과시각 필드는 없다. 9월8일 17:45 명목 슬롯의 재시도는 17:50 이후 실제 호출이므로 과거 17:45의 응답으로 해석하지 않는다. 자세한 결과는 `actual_collection_windows_v02.csv`, 파일별 해시는 `actual_collection_files_v02.csv`에 있다.

기존 저장 원장 262행, 정상 JSON 259개, 예측 항목 6,354개를 다시 집계했다. 6일간 성공 슬롯은 259/288, 준비 관측일을 제외하면 229/240이다. 정상 빈 응답은 5개이며 무효 정류소 판정이나 기본서비스 충족 판정에 사용하지 않는다. 호출 시각 준중복을 반영한 전체 실효 슬롯은 258/288이다. 신규 API 호출은 없다.

공동주택 21,690행, 건축물 표제부 4,067행, 행정동 세대수 원자료, 지오코딩 및 정류소 자료는 보관·프로파일링 대상으로 포함했다. 사용승인일과 실제 입주일은 다르고 행정동과 사업지구의 경계도 다르므로 누적 피해 세대·일은 산출하지 않는다. 명시된 MOCK 표식 부재만으로 합성 자료 부재를 증명하지 않는다.

## 전수 목록과 확인 범위

`all_files_v02.csv`는 프로젝트와 제공된 다운로드 폴더의 파일별 목록이다. `category`, `read_status`, `duplicate_of`, `semantic_review`를 구분한다. 파일을 바이트로 읽거나 기계 판독했다는 사실을 의미 검토 완료로 바꾸지 않는다. 목록 생성 후 작성한 배포 산출물은 별도의 패키지 manifest로 확인한다.

다운로드 폴더의 `transport-gap-audit_submission_v1` 3,991개 파일은 기존 정제 배포본과 모두 바이트 일치했다. 별도 수정된 파일은 발견되지 않았다. 비교는 `download_copy_comparison_v02.csv`에 기록했다. Starter ZIP 내부 멤버와 Office/HWPX 내부 파일은 `archive_members_v02.csv`에 있다.

지도 이미지 4개 및 기존 표·문서 페이지 이미지 5개를 확인했다. 텍스트 추출이 되지 않는 미사12·16단지 예비입주자 모집공고 PDF는 18페이지를 렌더링해 문서 구성과 해당 범위를 확인했다. 이는 2023년 예비입주 공고로 2014년 미사 최초 입주의 근거로 사용하지 않는다. 상세 조건 전부의 OCR 검증은 수행하지 않았다. 이 범위는 `visual_review_v02.csv`에 기록한다.

일부 기존 pytest 캐시 폴더는 접근 권한 오류로 내부 열거가 되지 않았다. 연구 입력에서 제외하며 `inventory_errors_v02.csv`에 경로와 이유가 남는다. 개인 신청서·서명·재학증명서·키 관리파일과 무관한 개인 문서는 배포에서 제외한다. 이 제외를 데이터 검토 완료로 계산하지 않는다.

## 배포 및 남은 검토

V01은 보존하고 V02 논문·표·그림·README·감사 자료를 추가한다. 배포 시 과거 키가 포함된 원본 Git 이력을 재사용하지 않고 기존 정제된 비공개 저장소의 이력에 커밋한다. 비밀값 검사와 원본/배포 해시는 V02 패키지 검증에 기록한다. 내부 로그 중 개인정보 또는 자격증명 위험이 있는 자료는 원본을 수정하지 않고 정제하거나 제외한다.

미검수 15행, 검수 완료 자료의 인용 위치·문자열 보완, 동탄2 실제 최초 입주의 사후 증거, 김포 6월17일의 직접 근거, 다산 최초 입주와 준공/개통 구분은 미해결 또는 추가 검토 대상이다. 이들을 확정값으로 보고하지 않는다. 따라서 전수 목록을 제공하더라도 ‘누락이 없다’는 보증은 하지 않는다.
