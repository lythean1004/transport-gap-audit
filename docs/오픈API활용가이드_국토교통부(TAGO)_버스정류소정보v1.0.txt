버스정류장 정보는 대중교통 시스템에서 중요한 데이터로, 
정류장의 위치, 명칭, 식별 정보(ID, ARS 번호 등)를 
제공하여 이용자와 운영자가 효율적으로 버스를 이용하고 
관리할 수 있도록 합니다. 주요 정보에는 
지역정보(시·도, 시·군·구, 읍·면·동), 정류장 ID, 
BIMS ID 등이 포함됩니다.
