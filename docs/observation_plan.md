# 버스 도착정보 관측 계획 (7D 스냅샷 수집 가이드)

본 문서는 TAGO 버스도착정보 API(`getSttnAcctoArvlPrearngeInfoList`)를 활용하여 게이트 통과 정류소의 실시간 도착 스냅샷을 수집하기 위한 스케줄링 및 운영 지침서입니다.
**Windows 작업 스케줄러(schtasks) 명령은 문서화 전용이며, 시스템에 자동 등록하지 않습니다.**

- **관측 대상 정류소**: 1개소 (`evidence/stop_registry.csv` 기준 `human_verified` 완료 건)

- **모니터링 시간대 (Asia/Seoul)**:
  - 오전 첨두: `07:00 ~ 09:00` (2시간, 07:00부터 08:55까지 5분 간격 24개 슬롯)

  - 일일 승인 트래픽: **10,000건/일** (하드스탑 5,000건 대비 일일 0.96% 소비로 안전 한도 내 운용)

## 3. Windows 작업 스케줄러(schtasks) 등록 명령 (참고용)

스케줄러 작업은 오전 및 오후 2개로 분리하여 등록합니다.  
아래 명령문의 `<PROJECT_ROOT>` 부분을 실제 프로젝트 절대경로(예: `C:\Users\parkd\new project\Transport-gap-audit`)로 치환하여 PowerShell(관리자 권한)에서 실행할 수 있습니다.

> [!CAUTION]
> 아래 명령문은 **실행용이 아닌 문서화 참고용**입니다. 자동 실행을 금지하며 필요 시 관리자가 수동 검토 후 등록하십시오.

### (1) 오전 모니터링 작업 등록 (07:00 ~ 09:00, 5분 간격)
```powershell
schtasks /Create /TN "TAGO_Arrival_AM" /SC WEEKLY /D MON,TUE,WED,THU,FRI /ST 07:00 /RI 5 /DU 02:00 /TR "cmd /c cd /d \"<PROJECT_ROOT>\" && python -m src.collectors.arrival_snapshot" /F
```

### (2) 오후 모니터링 작업 등록 (17:00 ~ 19:00, 5분 간격)
```powershell
schtasks /Create /TN "TAGO_Arrival_PM" /SC WEEKLY /D MON,TUE,WED,THU,FRI /ST 17:00 /RI 5 /DU 02:00 /TR "cmd /c cd /d \"<PROJECT_ROOT>\" && python -m src.collectors.arrival_snapshot" /F
```

### (3) 주의사항 및 등록 결과 검증
- `/SC MINUTE` 에는 `/D(요일)` 를 함께 쓸 수 없다. 요일 제한이 필요하므로 `/SC WEEKLY` + `/RI(반복 간격 분)` + `/DU(지속 시간)` 조합을 사용한다.
- 등록 후 반드시 아래로 실제 트리거를 확인한다:
  ```powershell
  schtasks /Query /TN "TAGO_Arrival_AM" /V /FO LIST
  ```
  출력에서 "다음 실행 시간"이 다음 평일 07:00 인지, "반복: 간격"이 5분인지, "반복: 기간"이 2시간인지 확인한다.
- 확인 결과가 다르면 작업 스케줄러 GUI 에서 트리거를 직접 수정하는 편이 빠르다.

## 4. 등록 전 사전 확인 체크리스트

1. **`TAGO_SERVICE_KEY` 사용자 영구 환경변수 등록 확인**:
   - 현재 터미널 세션의 임시 환경변수는 작업 스케줄러 세션으로 전파되지 않습니다. 사용자/시스템 환경변수에 영구 등록되어 있는지 확인하십시오.
   - **확인 명령어**:
     ```powershell
     [Environment]::GetEnvironmentVariable("TAGO_SERVICE_KEY", "User")
     ```
2. **PC 절전 모드 및 전원 설정 점검**:
   - 윈도우 절전 모드 진입 또는 PC 종료 시 백그라운드 예약 작업이 실행되지 않으므로, 수집 기간 동안 해당 시간대 절전 모드가 해제되어 있어야 합니다.
3. **첫 슬롯(07:00) 직후 원장 누적 육안 검증**:
   - 수집 개시 첫날 07:00 직후 `evidence/arrival_ledger.csv`에 첫 행이 정상 기록되는지 및 `evidence/arrival_raw/` 하위에 JSON 파일이 생성되는지 직접 확인하십시오.
4. **수집 창 밖 호출 정상 동작 이해**:
   - 수집기가 07:00~09:00, 17:00~19:00 외의 시각에 트리거될 경우 "수집 창 밖" 로그를 남기고 종료 코드 `0`으로 정상 종료하므로 이는 결함이 아닙니다.
